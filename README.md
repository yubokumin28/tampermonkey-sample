# Tampermonkey の見本

Tampermonkey(タンパーモンキー)の「入れる・止める・外す」を練習するための、いちばん小さな見本です。

- 動くのは https://example.com だけ。見出しを「Tampermonkey で書き換えました🦭」に変えます
- ほかのサイトでは何もしません。外へは何も送りません
- 入れ方のページ: https://yubokumin28.github.io/tampermonkey-sample/

## 入れ方
1. Chrome に Tampermonkey を入れる
2. chrome://extensions → Tampermonkey の「詳細」→「ユーザー スクリプトを許可する」をオン
3. 下の URL を開いて「インストール」
   https://raw.githubusercontent.com/yubokumin28/tampermonkey-sample/main/tampermonkey-sample.user.js
4. https://example.com を開く

## 外し方
Tampermonkey のアイコン →「ダッシュボード」→ この見本の行のゴミ箱。

🐒 Tampermonkey の見本

example.com の一番上に緑の札を出すだけの、いちばん小さなユーザースクリプトです。入れる・止める・外すの練習にどうぞ。

📥 ダウンロード

先に Chrome へ Tampermonkey を入れて、「ユーザー スクリプトを許可する」をオンにしてから押してください。

Tampermonkey の見本をダウンロード

押すと Tampermonkey のインストール画面が開きます。ファイルを保存する作業はありません。

🧭 入れ方

  1. Chrome ウェブストアで Tampermonkey を追加する
    Tampermonkey(Chrome ウェブストア)
  2. アドレス欄に chrome://extensions → Tampermonkey の「詳細」→「ユーザー スクリプトを許可する」をオン
  3. 上の緑のボタンを押す → Tampermonkey の画面で「インストール」
  4. https://example.com/ を開く。一番上に緑の札「🦭 Tampermonkey で書き換えました」が出ていれば成功です

🧹 止め方・外し方

  1. 止める: Chrome の右上の Tampermonkey のアイコン → 見本の緑のスイッチを切る
  2. 外す: Tampermonkey のアイコン →「ダッシュボード」→ 見本の行のゴミ箱

この見本は example.com でしか動きません。ほかのサイトの表示は変えず、外へ何も送りません。中身は GitHub で誰でも読めます。
